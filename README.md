  # Verity Edit Song

  **This resource pack changes Verity's favourite song (verity_disc) to the signature edit song.**

  [![Available on Modrinth](https://img.shields.io/badge/Available_on-Modrinth-00AF5C?style=for-the-badge&logo=modrinth&logoColor=white)](https://modrinth.com/resourcepack/verity-edit-song)

</div>

---

⚠!This Resource Pack is for use with VERITY JE. It will not work with any other mods.!⚠

Over the past week Verity has been the star of the show. Verity has his own "Signature Edit Song" but is not included in Verity JE, a fan-made verity mod, based off ThatMob's video.

This resource pack brings his song back by replacing Verity's "favourite song" (AKA. verity_disk.ogg) with his edit song.
