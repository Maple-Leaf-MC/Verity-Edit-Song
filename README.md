  # Verity Edit Song

  **This resource pack changes Verity's favourite song (verity_disc) to the signature edit song.**

  [![Download on Modrinth](https://raw.githubusercontent.com/Evergreen-Labs-MC/PvP-Tweaks/main/assets/badges/modrinth.svg)](https://modrinth.com/resourcepack/verity-edit-song) [![View on GitHub](https://raw.githubusercontent.com/Evergreen-Labs-MC/PvP-Tweaks/main/assets/badges/github.svg)](https://github.com/Maple-Leaf-MC/Verity-Edit-Song/)

</div>

---

⚠!**This Resource Pack is for use with VERITY JE. It will not work with any other mods.**!⚠

Over the past week Verity has been the start of the show.
Verity has his own "[Signature Edit Song](https://www.youtube.com/watch?v=JaawfHA6njA)" but is not included in Verity JE, a fan-made verity mod, based off ThatMob's video.

This resource pack brings his song back by replacing Verity's "favourite song" (AKA. verity_disk.ogg) with his edit song.

This resource pack is maintained by Isaac Firth and part of the Maple Leaf Studios Organization.
